# Third-party language tools

WanaKana 5.3.1 — https://github.com/WaniKani/WanaKana — MIT. Lazy romanization/kana conversion after an explicit user click; no native IME replacement.

winkNLP 2.4.0 — https://github.com/winkjs/wink-nlp — MIT. Opt-in English tokenization, POS and lemma analysis in an isolated, disposable browser worker.

wink-eng-lite-web-model 1.8.1 — https://github.com/winkjs/wink-eng-lite-web-model — MIT. Local model data; no text is sent to an NLP service.

Kuroshiro 1.2.1 — https://github.com/hexenq/kuroshiro — MIT. Optional worker initialization and kana reading normalization; structured React ruby is used instead of trusting generated HTML.

Kuroshiro analyzer Kuromoji 1.1.0 — https://github.com/hexenq/kuroshiro-analyzer-kuromoji — MIT. Local contextual tokenization/basic forms with an explicit same-origin dictionary path.

Kuromoji 0.1.2 — https://github.com/takuyaa/kuromoji.js — Apache-2.0. Optional 17,791,956-byte compressed IPADIC dictionary. Its NAIST/ICOT data notice is retained verbatim in `public/licenses/kuromoji-ipadic-NOTICE.txt`; dictionary files are copied unmodified during build.

path-browserify 1.0.1 — https://github.com/browserify/path-browserify — MIT. Browser-only path compatibility for the analyzer; no filesystem access. Transitive runtime license texts for async, doublearray, zlibjs, lodash and Babel runtime are retained with the upstream notices.

The complete upstream notices are retained in public/licenses and included in the static distribution. No Lute, ts-fsrs or Recharts source is installed/copied. Exact dependency versions and integrity are locked in package-lock.json. No GPL/AGPL code is copied.
