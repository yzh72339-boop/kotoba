# Third-party language tools

WanaKana 5.3.1 — https://github.com/WaniKani/WanaKana — MIT. Lazy romanization/kana conversion after an explicit user click; no native IME replacement.

winkNLP 2.4.0 — https://github.com/winkjs/wink-nlp — MIT. Opt-in English tokenization, POS and lemma analysis in an isolated, disposable browser worker.

wink-eng-lite-web-model 1.8.1 — https://github.com/winkjs/wink-eng-lite-web-model — MIT. Local model data; no text is sent to an NLP service.

The complete upstream notices are retained in public/licenses and included in the static distribution. No Lute, Kuroshiro, Kuromoji, ts-fsrs or Recharts source has been copied or installed by this update.
