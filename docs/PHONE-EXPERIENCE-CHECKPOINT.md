# Kotoba 2.6 — 手机核心体验断点

## 本轮范围

沿用当前 2.6 源码、Next.js、Supabase、PWA、Auth/RLS、SRS、稳定课程 ID、笔记、缓存和同步。无依赖升级、数据库迁移改动或生产 SQL 写入。资料保持 667 词汇卡 / 150 语法 / 60 阅读，内容增量 0。

## 手机改动

- 语法/阅读练习在手机每次只显示一题。选择后手动提交，解析在本题下方；提交不会自动跳题，明确点击下一题。桌面保留多题展开。
- 保存稳定 questionId，刷新/备份/同步后继续同一题；旧草稿或失效题号安全回退到未完成题。答案选项顺序、卡片 ID、成绩和原记录不变。
- 保留上一题、错题重练和最终提交。打开题目后滚动到题干并移动可访问焦点，触控按钮至少 44px。
- 手机资料库提供直接搜索；等级/主题等放入抽屉。抽屉不重复搜索框，避免打开筛选就唤起软键盘。
- 手机标题使用中文；语法/阅读子页面归属资料库，复习/词汇归属学习，设置归属我的。路由与深链接不变。
- 首页/学习页显示当前语言等级的真实计划进度，恢复暂停计划时不显示其他范围的状态。新计划三步，旧四步计划继续兼容。
- 底部每日操作栏测量自身高度，正文留白、卡片评分和连接提示采用这个高度。操作说明可换行；软键盘出现时隐藏评分栏。
- 卡片计时复用已验证的 pagehide/pageshow 处理，避免后台缓存暂停时间被计入。
