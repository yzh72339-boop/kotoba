## 视觉与实现

新增 app/expressive.css，由 expressive-experience 控制范围。浅色采用淡紫灰画布、深色采用墨紫画布；核心任务使用墨色/电光紫渐变、冷白按钮、静态环形光晕。次要资料列表保持低强度。主题、正文/阅读外观设置与原功能兼容。

手机首页显示真实计划的语法/阅读标题、预计分钟、稳定三步/旧四步进度与实际学习分钟。开始按钮、暂停/恢复、课程 ID 和保存逻辑不变；无目录时明确准备状态，不伪装课程。

学习题干、选中答案、提交与解析有统一色彩/比例，选项公开 aria-pressed。章节与解析淡入，进度使用 transform；原翻卡、返回滚动位置、软键盘安全区、抽屉焦点恢复继续工作。课程加载沿用现有 skeleton。

模糊效果只在能力充足设备启用。prefers-reduced-motion、saveData、≤4GB 内存或≤4逻辑核关闭复杂效果；所有设备保留静态渐变和可操作按钮。没有连续动态背景或新增依赖。

交互检查：
1. 首屏能找到开始/继续按钮，显示真实课程；开始后恢复同一计划。
2. 进入语法 → 例句/讲解 → 练习 → 选择/提交，解析紧邻题目，手动下一题。
3. 提交后刷新，稳定题号与解析保持；错题重练后下一步阅读。
4. 阅读切换字号、译文、查词、收集、输入笔记；关闭面板位置不变，键盘不遮挡。
5. 完成题目 → 保存/同步 → 查看结果 → 返回；连续点击不重复完成。
6. 对比 reduced motion / 省流模式；离线/重连、第二设备、安装版更新仍须真机验收。
